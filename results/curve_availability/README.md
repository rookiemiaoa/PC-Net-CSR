# curve_availability —— 「曲线可用性」第二坐标的原始证据

本目录是论文 §3.6 / §4.10 / 附录 B.2–B.3 的全部原始证据。它回答一个问题：

> 把同一个「窗内质心」中心估计器施加到一个骨干自身的重建相关性曲线上，
> 该曲线是否具备时间定位能力？——若不具备，CSR（中心平移精化）会显著**有害**。

## 1. 判据

对每个工作点定义两个量（均与真值无关，除方向准确率需要真值用于离线核对）：

- `a` = **方向准确率**：在确有偏移的子群 `|c_b − c_gt| ≥ 0.08` 上，
  曲线质心估计出的位移方向与真值方向一致的占比。`a = 0.5` 即抛硬币。
- `ΔmIoU` = CSR 相对该工作点基础框的 mIoU 变动。

**结论（18 个互异工作点）**：沿 `a` 符号完全单调 —— 所有 `Δ < 0` 的点其 `a ≤ 0.510`，
所有 `Δ > 0` 的点其 `a ≥ 0.569`，实测夹逼区间 `a* ∈ (0.510, 0.569)`。

### 相关但独立的两组证据

- `w41_gauss_read.json` / `w42_gauss_shrink.json` —— **第二条读取路径**（不替换任何模块，
  直接读模型原生高斯参数并按 NLL 归一化合成曲线）。PC-Net 上方向准确率 0.824 > 点掩码的 0.776，
  说明第二坐标不是「点掩码替换」这一干预的产物；但原生曲线需按 `s = 0.30` 缩放才转为 +0.46 mIoU，
  说明瓶颈在「兑现」而非「信息」。
- `w43_pps.json` —— PPS 的结构探测（`has_fc_gauss = false`、`fc_mask['gauss']`
  渐进式 ModuleList `[2,4,6,8,10,12,14]`）与原生参数读取。PPS 的方向准确率 0.79–0.81
  与 PC-Net 同量级，因此它**不是**落在空档内的骨干，其不可同等后处理是**接口结构**问题。
- `w44_effectsize.json` —— 效应量（配对 d_z、Cliff's δ、逐样本胜负计数）。

## 3. 两条诚实限定

1. 13 个轨迹点来自 3 个骨干，彼此高度相关，**不是 13 个独立骨干**。夹逼区间的收紧来自
   `a` 取值范围的扩大而非独立样本的增加 ⇒ 它仍是**实测夹逼区间，不是置信区间**。2. 落在 (0.510, 0.569) 内的只有训练中途的工作点，**没有骨干的收敛点落入其中**。
   「空档被填上」的确切含义是第二坐标的取值区间被覆盖，而不是新增了一个处于该区间的骨干。

一个 B.2 未曾预期的观察：`a` 越过门限的时刻远早于训练收敛 —— CNM 在第 2 个 epoch
（中心 MAE 0.222，收敛时 0.198）就已经 `a = 0.569 > a*`，而 CPL 与 CCR 在被扫描的每个
epoch 上 `a` 都停留在 0.44–0.51、从未越过门限。这与「`a` 是骨干固有的曲线定位能力，
而非训练成熟度的函数」一致。
