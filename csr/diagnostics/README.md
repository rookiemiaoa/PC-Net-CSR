# `csr/diagnostics/` —— 被证伪的路线（负结果）

这一目录是**科学性证据**，不是可用工具。它记录了从「修边界」转向「修中心」之前的完整排查过程：
**6 个脚本、300+ 个变体，全部未能在 Charades-CG 上同时满足"短动作不降 + 长动作显著增"。**

保留它们的理由：这些负结果正是 `docs/CSR_METHOD.md` §1 那句判断（扩框存在结构性方向偏置）
的实证基础，也解释了为什么最终方案不是"再调一个阈值"，而是**换一根轴**。

---

## 1. 目标口径（当时定下的判据）

| | ΔR1@0.5 | ΔR1@0.7 | ΔmIoU |
|---|---:|---:|---:|
| 短动作（gt ≤ 0.35） | ≥ −0.2pt | ≥ −0.3pt | ≥ −0.2pt |
| 长动作（gt > 0.35） | ≥ **+2pt** | ≥ **+5pt** | — |
| 整体 | ≥ 0 | > 0 | > 0 |

> 为什么必须在**阈值口径 + 短/长分桶**下扫：早期扫描只看 mean IoU，
> 短动作只掉 0.17pt，看起来无害；但扩框把一批短样本的 IoU 从 0.5x 压到 0.4x，
> **mean IoU 几乎不动，R1@0.5 却掉 3.0pt**（跨线效应）。
> 口径选错会让整轮排查得出相反结论 —— 这是 `diag32_shortlong.py` 存在的意义。

## 2. 脚本与结论

| 脚本 | 路线 | 关键结果 | 判决 |
|---|---|---|---|
| `diag32_shortlong.py` | 确立分桶口径；阻尼/门控族的前沿扫描 | 短 −2.98 / 长 +10.49（标准 RBR k=0.15） | 口径修正；纯全局阻尼只能同比例缩放，**无法达标** |
| `diag35_edgegrow.py` | 边界外推 Edge-Grow：从框边界**外侧**往外长，相关性仍接近峰值才继续 | 短伤 −2.98 → **−0.45**（6.6×），但长 @0.7 只剩 +4.19 | 只是"更少动手"，**不是"更会分辨"** |
| `diag36_gate.py` | 用 Edge-Grow 的布尔判定当门控，开关 RBR 的扩展量 | 最佳 `EGS_a0.60_m1`：短 −0.99 / 长 +2.57 / +7.59 | 布尔"平台/非平台"判据不够，**短仍为负** |
| `diag37_symctr.py` | 对称生长（SYM）+ 尺度无关的框内外对比度门控（CTR） | 最佳 `CTR_t60_m1`：短 −0.80 / 长 +2.49 / +6.92 | **仍为负** |
| `diag38_signal.py` | ★ **逐侧决策的信号筛选**：对候选判据逐个算 AUC | "边框外是否有平台" AUC ≈ **0.52**（与抛硬币无异）；"对比度" ≈ 0.45 | **决定性诊断：信号本身不可分** ⇒ 这解释了 300+ 变体全灭 |
| `diag39_kratio.py` | 聚焦 `kratio = flood核宽 / top-1框宽`（AUC ≈ 0.65）与 `margin = nll(top2) − nll(top1)` | kratio 在校准/测试、短/长四路一致 | 最有希望的两个信号，但仍不足以达标 |

### 一个实现教训（`diag38` 修正的 bug）

`diag37` 的对比度定义 `rho = mean(z_out) / mean(z_in)`，分母是**框内 z 均值**。
`Z` 是逐样本 z-score，**框内均值经常接近 0** ⇒ 分母趋零 ⇒ `rho` 爆到 `1e5 ~ 1e6`
（日志里出现的 `短=200787` 就是这个）。此时该信号等于**未被测量**。
`diag38` 改用 0~1 归一的 `RN = (REL − min) / (max − min)`，并给分母设下限 0.05。

> ⇒ **不要把 `Z` 的框内均值当分母。** 这条也适用于一切"框内/框外对比"类判据。

## 3. 另一个方向的天花板（用 gt，仅作说明）

`diag37` / `diag38` 顺带算的几个 oracle 上界，说明了"有没有解"：

| 上界 | 短 | 长 @0.5 | 长 @0.7 | 结论 |
|---|---:|---:|---:|---|
| `ORACLE_gate`（逐样本最优门控） | +1.29 | +5.56 | +12.48 | **存在解**，缺口是逐样本选择而非全局幅度 |
| `ORACLE_sym`（对称生长上界） | +0.46 | +0.83 | — | 对称生长**结构性无效**（`min(ΔL, ΔR)` 掐掉增益） |
| `ORACLE_side`（逐侧 oracle） | +2.20 | +8.04 | +17.66 | 天花板最高，但**无 gt 判据不可分** ⇒ 收益无法在弱监督下兑现 |
| `ORACLE_c`（只换 gt 中心、框宽不变） | +20.7（mIoU） | — | — | ⇒ **转向中心轴** |

## 4. 运行

```bash
python csr/diagnostics/diag32_shortlong.py     # 建议先跑这个，建立口径直觉
python csr/diagnostics/diag38_signal.py        # 决定性诊断，最值得读
```

脚本用 `CACHE_DIR`（默认 `csr/analysis/feat_cache`）缓存逐样本相关性曲线：
首次运行会前向一遍模型，之后秒级迭代。`diag36/37/38/39` 支持 `NO_CACHE=1` 强制重算。
